# 运行环境与依赖

你反馈的主机已有 ROS Humble desktop、rclpy、RViz、robot_state_publisher、joint_state_publisher_gui、xacro、colcon、NumPy 和 SciPy。当前终端没 source ROS，所以最初找不到 ros2；加载 `/opt/ros/humble/setup.bash` 后关键包可以解析。统一入口已代为完成此步骤，不需要修改 `.bashrc`。

没有发现 MoveIt、Conda、PyTorch、MuJoCo 或 Isaac；这是检测范围内的结果，不证明其他磁盘或容器绝对没有安装。Docker 已安装，但普通账户无权读取服务；本工程不依赖 Docker，不修改用户组或 Docker 权限。

ROS 构建和展示若提示缺少依赖，可按实际缺项安装：

```bash
sudo apt update
sudo apt install python3-colcon-common-extensions ros-humble-ament-cmake \
  ros-humble-robot-state-publisher ros-humble-joint-state-publisher-gui \
  ros-humble-rviz2 ros-humble-xacro ros-humble-rclpy
```

这些不是必须重复执行的命令；先运行 `bash project.sh build`。没有安装 MoveIt 不妨碍当前模型展示和 CPU MuJoCo 检查。需要重跑旧 MoveIt 碰撞检查时，再单独准备 MoveIt 环境。

ROS 默认安装入口为 `/opt/ros/humble/setup.bash`。若未来搬到另一台同为 Humble 的机器，可临时覆盖：

```bash
OPENARM_ROS_SETUP=/另一位置/humble/setup.bash bash project.sh build
```

构建前检查会报告关键包是否来自预期 `/opt/ros/humble`；本次交付针对该主机的标准安装。若真正换到非标准 ROS 前缀，还需同步更新 `scripts/ros_preflight.py` 的前缀检查。

域号如需调整，所有终端使用相同的工程变量：

```bash
OPENARM_ROS_DOMAIN_ID=189 bash project.sh display gui:=false
OPENARM_ROS_DOMAIN_ID=189 bash project.sh pose open_hand
```

旧 catkin 工程不会自动加入本项目。新工程构建缓存只在 `workspace/` 下；目录移动后应在新位置重新构建，不能依靠原位置的安装缓存。不要手工 source 旧同名描述包再绕过统一入口启动。

`nvidia-smi` 中的 CUDA 11.4 表示驱动所支持的 CUDA 级别，不代表安装了 Toolkit；没有 nvcc 不影响 ROS 或 CPU MuJoCo。当前驱动和被截断的显卡型号不足以确定可安装哪个 PyTorch CUDA wheel，因此本包不预装或硬编码 GPU 训练依赖。

官方 Isaac Sim 5.1 的版本化要求页列出 32 GB 内存、16 GB 显存和更新的驱动要求；你报告的约 16 GB 内存、6 GB 显存和 470 驱动不符合这一配置。该版本页本身已标注不再支持，不应据此直接选择 5.1 安装。保留 USD 是为了后续在合适设备上迁移，不将它设为此台式机的默认运行入口。
