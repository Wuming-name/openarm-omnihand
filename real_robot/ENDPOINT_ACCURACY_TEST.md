# J2 端点精度验收

用户要求运动中允许 J2 跟踪滞后，到达端点后验收位置精度。新增显式选项 `--endpoint-only`，未提供该选项时保留原逐周期误差保护。此选项仅适用于单轴 J2 往返测试，不修改完整 ROS2 或 PPO 部署程序。

启用时 J2 运动中的目标跟踪误差仍计算并记录，用于 PD 生成力矩和故障分析，但超过 0.02 rad 不再直接终止运动。其他六轴偏移仍限制在 0.005 rad，所有轴实际运动走廊、硬限位、速度、力矩、温度、通信及模型接触保护不变。

出去用 6 秒、端点保持 1 秒。进入返回阶段前，检查 J2 距离出去端点不超过 0.02 rad（约 1.15°），失败就停止，不能以未动而最终回到原位判定成功。随后 6 秒返回、起点保持 1 秒，七轴最终返回误差须均不超过 0.005 rad（约 0.286°）。加上起始保持共 15 秒。此修改不会保证物理上一定到达目标；误差不合格仍报告失败。

示例：

```bash
python -m real_robot.probe &&
python -m real_robot.plan_startup --run outputs/ppo/run_20261028_164711_538719 &&
python -m real_robot.startup_joint_test --run outputs/ppo/run_20261028_164711_538719 --j2-gain-scale 0.4 --endpoint-only --execute
```

默认增益、重力前馈、目标幅度及电机参数不变。运动期间控制力矩会随误差增大而增加，仍受既有力矩限制。测试仍须可靠支撑且不阻碍运动；正常或异常退出都会尝试失能，异常不保证先返回。OmniHand 保持现有姿态，此程序不操作手部、不执行 A→B 策略。
