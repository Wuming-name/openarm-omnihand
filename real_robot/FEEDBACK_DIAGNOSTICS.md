# 保持测试的速度/位置保护诊断

用户报告20261028_213345显示：完成45个控制周期，短时平均499.29Hz、最大周期2.129ms；七轴均观测到46次反馈更新。该数据只覆盖约0.09秒，不等于3秒500Hz验收通过。停止原因为位置或速度保护，未记录拒绝样本，因此原max_drift=0.001144rad不能证明触发时位置偏差没有越界，也不能据此断言某轴超速或速度噪声。

修订后commission_hold在保护触发前更新最大位置偏差，使用stop_details记录q、目标q、逐轴误差、速度、最大误差/速度的轴号及两个阈值是否越界。模型子进程中的同类异常也传回结构化字段。保护阈值、控制增益与退出失能行为均未放宽。

先退出所有机械臂控制程序，机械臂可靠支撑。运行只读反馈观察：

```bash
cd /home/lsk/openarm_v1_ws/src/openarm-omnihand-project
python3 -B -m real_robot.feedback_probe --seconds 5
```

工具只读取既有参数并以约100Hz发送官方0xCC状态查询，不发送使能、失能、MIT目标、力矩、归零或写寄存器。任一轴不是未使能status=0时停止，反馈缺失或陈旧也会失败。报告中每轴包含位置跨度、反馈速度范围与协议速度量化步长；完整时间戳样本写入outputs/real_robot/*_feedback_probe.json。

位置几乎不变而速度反馈不为零，可能与速度估计、量化、机械微动等有关；不能自动归零或认定全是噪声。工具保留原始解码值，不修改量程、不滤波、不通过增大阈值自动判为可控。应对照实物是否静止、失能状态与采样结果再决定后续处理。

本地36项测试通过，包括拒绝样本的轴号和误差完整记录、跨进程异常详情保留、速度值不被位置静止假设覆盖、缺失轴拒绝汇总。实机结果待用户验证。
