# J6速度保护后的低增益调试

用户报告20261028_214256_059474的明确触发值为J6速度反馈-0.1098901rad/s，超过固定位置测试0.1rad/s阈值；该样本位置偏差0.0003815rad，未超过0.005rad。控制运行44周期、平均499.16Hz；这不是完整3秒验收通过。失能采样下七轴位置不变、速度反馈最大约0.0366rad/s，不能据此把使能后的0.10989rad/s自动当成噪声。

为降低软件PD对微小误差/反馈变化的力矩响应，新增`--gain-scale 0.2`有支撑测试。它同时缩放测试进程中的Kp/Kd，保持目标不动，gravity/bias前馈、力矩限幅和所有保护阈值不变。只是调试参数，不是厂家为该负载推荐的参数，也不是原训练闭环的最终部署配置。不能据此认定根因已证明或原策略可以直接执行。

```bash
cd /home/lsk/openarm_v1_ws/src/openarm-omnihand-project
source .venv-ppo/bin/activate
python -m real_robot.commission_hold \
  --run outputs/ppo/run_20261028_164711_538719 \
  --backend socketcan --execute --seconds 3 \
  --stationary-baseline --gain-scale 0.2
```

**机械臂全程可靠支撑，退出其他控制程序。结束/异常/中断会尝试失能，失能后不能托住负载；通信故障也可能使失能未送达。** 初始电机必须均失能，手部保持现状，不前往A/B。若速度保护再次触发，不反复重试或增加阈值，先分析轨迹记录与实物是否振动。

有效测试增益为：Kp=[20,24,16,16,6,5,4]，Kd=[2,2.4,1.6,1.6,0.6,0.5,0.4]。J6从Kp25/Kd2.5降为Kp5/Kd0.5。保存的训练task/config/model/权重均不修改。gain_scale范围0.1～1.0，默认1.0保留原行为。报告同时列出训练与有效增益，并明确training_gains_unchanged=false。

新增`trace_file`指向独立JSON，保存最后最多500个控制周期的位置、速度和计算出的指令力矩。被拒绝样本保留在记录中，其commanded_torque_nm可能为null，表示该周期未产生新的力矩值；非null仅表示计算出的指令，并非电机实际输出或收到的证明。高频循环不打印记录，失能尝试后才写文件。完整报告仍记录stop_details的触发轴和值。

本地38项测试通过，包含缩放后PD公式、前馈不缩放、训练参数不被改写、原速度保护仍生效与非法缩放值拒绝。20%增益下1500步MuJoCo静态保持通过，轨迹文件包含最后500周期。该理想仿真并未复现真实J6异常，实机改善与否仍需报告验证。如果最终采用不同增益，需要在相应闭环条件下重新评估策略，必要时重训，不能把调试成功等同于原策略部署通过。
