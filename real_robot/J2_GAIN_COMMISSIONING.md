# J2 单轴增益诊断

2026-10-29 的 J2 往返测试约 4.06 秒时，J2 从 0.016594 rad 仅移动到 0.017357 rad，而目标已到 0.037368 rad，触发 0.02 rad 跟踪误差保护。循环约 500 Hz，反馈正常，最大 J2 命令力矩约 0.637 Nm。用户确认没有支撑限制 J2 转动。静摩擦或驱动力不足是待验证假设，尚不能排除执行器设置、传动阻力或反馈问题。

新增 `--j2-gain-scale 0.4` 仅用于 J2 小幅往返诊断。J2 Kp 从 24 增至 48 Nm/rad，Kd 从 2.4 增至 4.8 Nm·s/rad；其他六轴保持 20% 增益。默认仍为 0.2。此处为主机计算 PD 后发送 MIT 力矩命令，不改变电机内部增益或写入电机参数。

轨迹、跟踪误差 0.02 rad、固定轴偏移 0.005 rad、速度 0.1 rad/s、模型接触、反馈、温度、力矩限制及退出失能逻辑保持原样。重力前馈不变，不添加固定力矩或积分项。新配置没有获得先前全局 20% 增益 PPO 仿真评估的实机认可，不用于完整 A→B 任务。

报告新增各轴实际使用的 Kp/Kd 和增益比例；轨迹新增电机反馈力矩及峰值，供对比计算命令与电机报告。反馈力矩本身不是经过标定的外部力传感器测量。

Ubuntu：

```bash
python -m real_robot.probe &&
python -m real_robot.plan_startup --run outputs/ppo/run_20261028_164711_538719 &&
python -m real_robot.startup_joint_test --run outputs/ppo/run_20261028_164711_538719 --j2-gain-scale 0.4 --execute
```

测试仍需要不阻碍运动的可靠支撑；正常及异常退出都会尝试失能，异常不保证先回到起点。不操作手部，不执行 J6、到 A、PPO 或到 B。若仍不跟踪，保留报告分析，不自动继续提高增益或取消误差保护。
