# 第一次小幅运动：仅J2向外并返回

用户Ubuntu启动规划20261028_220807通过：J2+0.06rad（3.44°）、J6+0.08rad（4.58°），退出后到A段满足原任务碰撞规则，完整候选约53.2秒。此工具**只测试第一段J2往返**，不执行J6、不前往A/B、不运行PPO、不控制手部。

## 行为

读取成功规划报告并校验任务模型/配置指纹。仅接受第一段shoulder_retreat，J2正增量0.02～0.08rad，其他六轴目标必须完全不变，单程6～10秒。用原模型重新采样向外和返回两条走廊，每方向161个姿态。允许恢复原有初始模型重叠，但不得出现新配对或超过初始深度0.5mm；这项有界运动例外不是全程严格无碰撞证明，不能延伸到完整A/B运动。

默认不打开CAN，只检查规划。使用--execute才使能并运行；七轴最初必须均失能，实测起点与规划每轴误差不得超过0.002rad，否则要求重新测量规划。使能前再次读取状态，避免模型进程准备期间姿态变化。

正常流程：保持1秒→J2最小加加速度向外6秒→保持1秒→返回6秒→保持1秒。0.06rad/6秒的参考峰值速度0.01875rad/s（约1.07°/s）。使用已实机通过的20%增益、500Hz软件PD和50Hz独立模型进程。手部保持当前姿态，不发送手部目标。

动态J2跟踪误差上限0.02rad；其他六轴保持误差仍为0.005rad。各轴实测角不得超出规划起终点范围外0.005rad，七轴速度阈值仍为0.1rad/s；保留反馈/调度、硬限位、温度和持续力矩保护。正常结束需返回起点误差≤0.005rad、平均循环≥475Hz、每轴新反馈更新≥周期数80%。这是独立小幅运动测试的跟踪窗口，不修改先前固定位置测试的阈值。

**机械臂必须全程可靠支撑，清理人员、线缆、桌椅在这段小幅运动范围内的干涉。正常返回后尝试失能；异常或Ctrl+C时会中途结束并尝试失能，不保证返回起点。失能后不能托住负载，通信故障也可能使失能无法送达。** 不依赖未验证的TIMEOUT。不要让其他控制程序同时发送指令。
