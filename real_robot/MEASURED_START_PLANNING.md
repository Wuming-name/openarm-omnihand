# 从本次实测位置规划

本说明替代 SCREENED_START_20261029.md、START_SCOPE_164521.md 中的历史起点匹配规则。历史读数现在仅作为自动测试数据，不用于运行时准入。

每次读取最新只读 probe，以本次七轴位置作为起点。未显式指定历史 probe 时，报告须在最近 60 秒内。七轴须未使能且协议匹配。

`startup_scope.py` 使用当前小幅测试的启动区域：J1/J2/J3/J4/J6/J7 为 ±0.1 rad，J5 为 ±0.15 rad，以包含实测约 0.124 rad 的姿态。这个区域是测试范围，不是机械限位或碰撞豁免。区域内姿态并非全部已验证安全；每次必须继续检查原模型硬限位、已限定的初始接触、逐点退离路径、到 A 的严格接触规则，以及 J2 出去与返回路径。失败时不执行。

`plan_startup.py` 的报告增加启动区域边界，起点仍记录在 q_start_rad；执行仍在使能前两次检查实际位置与新计划每轴差值不超过 0.002 rad。该值只用于确保新计划仍匹配实物，不再用于匹配历史快照。

18:07:39 的实测起点（J2=0.032616159304188486 rad）已在本地同配置模型完成筛选：J2 +0.04 rad、J6 +0.08 rad 后到 A 的路径通过。Ubuntu 仍会用实际保存模型重新筛选。

`--endpoint-only` 行为保持：运动中记录 J2 误差但不据此中断，出去后保持 1 秒、误差须不超过 0.02 rad；返回后保持 1 秒，七轴最终误差须不超过 0.005 rad。其他六轴偏移、实际运动走廊、速度、力矩、温度、反馈及模型接触保护不变。仍只做 J2 往返，不实际执行 J6、到 A 或 PPO。

```bash
python -m real_robot.probe &&
python -m real_robot.plan_startup --run outputs/ppo/run_20261028_164711_538719 &&
python -m real_robot.startup_joint_test --run outputs/ppo/run_20261028_164711_538719 --j2-gain-scale 0.4 --endpoint-only --execute
```

固定姿态基类也使用相同启动区域，避免规划与执行定义不一致；完整 ROS2 实机任务的校准门槛没有改动。需要可靠且不阻碍运动的支撑；正常和异常退出都会尝试失能，异常不保证先返回。程序不操作或持续监测手部。
