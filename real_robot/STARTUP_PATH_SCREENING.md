# 20%增益评估通过后的启动路径筛选

用户正式策略在20%增益下，名义20回合、随机化20回合均成功。末端误差名义约13.8～16.5mm、随机化约13.6～17.5mm。这是仿真筛选，不代表真实A→B运动通过。当前近零位的初始模型穿透仍存在，固定姿态保持的基线规则不能直接用于整条运动路径。

新增`plan_startup`只读取成功的失能七轴probe报告并在训练模型上筛选路径，不打开CAN、不使能、不写电机参数，也不提供执行运动参数。

```bash
cd /home/lsk/openarm_v1_ws/src/openarm-omnihand-project
source .venv-ppo/bin/activate
python -m real_robot.probe &&
python -m real_robot.plan_startup \
  --run outputs/ppo/run_20261028_164711_538719
```

自动选择最近60秒内的只读报告，要求七轴均失能、默认符号/零点映射、各轴绝对角不超过0.1rad。`--probe PATH`可指定历史报告用于离线复现，不要求60秒新鲜度，不能把历史结果当作当前姿态。

## 筛选规则

候选分为三个阶段：J2小幅向外、J6小幅调整、从退出姿态缓慢到训练A点。搜索J2增量0.04/0.06/0.08rad、J6增量0.08/0.10/0.12rad，不修改其他轴的退出目标。退出阶段各轴距初始角最多0.12rad。

初始两阶段显式接受已知四组模型重叠：底座/拇指mcp、pip、dip，及腕部link5_piece0/link7_piece7。初始深度仍受原基线最大范围限制。此为模型初始重叠的例外，不是整条路径无碰撞的证明。

每个阶段至少101个样本，最大关节插值步长不超过0.002rad：不允许新的接触配对；已有穿透不得比此前最浅值加深超过0.1mm；已经退出的配对不得重新出现。两段退出结束时必须在原任务穿透容差下无碰撞，后续到A段完全使用原严格碰撞阈值。各样本保持硬限位。该离散筛选不是连续碰撞检测，也不覆盖照片中的线缆、人员、桌椅等外部障碍。

时间按五次最小加加速度参考计算：每段退出至少6秒，到A至少20秒，同时限制启动速度/加速度为训练上限20%。本地使用用户之前反馈的关节读数复现时，候选J2+0.06rad（3.44°）/J6+0.08rad（4.58°）通过，后续到A约41.27秒，总计约53.27秒。必须在Ubuntu实际训练模型和新读数上重新计算，不能直接硬编码本地结果。

## 查看结果

报告保存`outputs/real_robot/startup_plan.json`，含模型/配置和源probe SHA、起终点、各段关节角、时间、采样数、各端点接触及被拒绝候选。`passed=true`只表示通过上述模型筛选；`motion_authorized=false`、`entire_path_strictly_collision_free=false`和`requires_initial_overlap_allowance=true`用于明确初始例外及物理验证边界。该文件不是实机执行凭证。

在Ubuntu图形桌面终端可加`--render`查看运动学预览：

```bash
python -m real_robot.plan_startup \
  --run outputs/ppo/run_20261028_164711_538719 --render
```

每次必须先刷新probe；也可为预览显式指定已知报告。预览按规划时间设置模型关节角，不进行动力学积分，不能据此确认低增益跟踪和负载承受能力。无DISPLAY时先去掉--render生成报告。规划和预览整个过程均不控制实物，手部保持现状。

本地43项测试通过，包含穿透减少允许、相对最浅值加深拒绝、退出后重新接触拒绝和新接触拒绝；使用此前测量角度的候选路径通过本地模型筛选。实机小幅退出、到A和PPO尚未执行，需后续独立验证。
