## 本模式的范围与限制

`--stationary-baseline`是**放宽特定初始模型重叠的有限位置保持测试**，不是已修好碰撞模型。它只用于当前已拍照的近零位，不得用作前往A或执行PPO的碰撞依据。

- 必须实机`--backend socketcan --execute`，七轴起初均未使能。
- 七轴初始角均须在±0.1rad以内，时间最多3秒。
- 初始重叠仅允许底座与拇指mcp/pip/dip三个已报告配对，穿透不超过25mm；以及link5_piece0与link7_piece7这一个配对，不超过4mm。阈值限定已观测问题的范围，不代表可接受的真实接触深度。
- 将初始模型穿透记录为基线。任何新配对，或同一配对加深超过0.5mm，立即结束测试。
- 固定目标为刚读到的位置，不能传入A/B或其他目标；任一轴偏离初始目标超过0.005rad（约0.29°）、速度超过0.1rad/s时退出。
- 其他反馈、调度、额定持续力矩、温度和硬限位检查保留。
- **机械臂必须全程可靠支撑。结束、异常或Ctrl+C会尝试发送失能，失能后无法托住负载；通信错误也可能导致失能指令无法送达。** 不依赖未验证的TIMEOUT。若实物实际接触底座或腕部有卡滞，不得使用本模式。

```bash
cd /home/lsk/openarm_v1_ws/src/openarm-omnihand-project
source .venv-ppo/bin/activate
python -m real_robot.commission_hold \
  --run outputs/ppo/run_20261028_164711_538719 \
  --backend socketcan --execute --seconds 3 --stationary-baseline
```

报告包含初始重叠、七轴位置、最大位置偏差、力矩、循环频率和反馈更新情况。即使`passed=true`也只表示本次固定目标测试通过；`collision_model_validated_for_motion=false`仍然成立。移向A/B前应单独修正并验证碰撞几何或起始路径，不能继承这项基线放宽。

本地31项测试通过，涵盖未知初始配对拒绝、初始过深/非有限拒绝、重叠加深拒绝、新配对拒绝、仅近零位及更紧的位置偏差限制。物理效果及实机500Hz性能仍待用户测试，模拟模型保留原始碰撞力，因此不提供模拟积分下的本模式“无碰撞成功”结论。
