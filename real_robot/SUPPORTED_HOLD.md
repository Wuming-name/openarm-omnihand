# 七轴有支撑 MIT 测试

此入口用于第一次使能/控制通信检查，不运行 PPO、不控制手部、不写 TIMEOUT、不归零，也不把未验证的标定标志改成 true。要求七轴起初均为未使能状态，避免接管其他控制器。

**机械臂必须全程可靠支撑。测试结束、Ctrl+C 或检测异常后，会向七轴逐一尝试发送失能命令；失能后电机不能托住负载，通信故障也可能使失能命令无法送达。** 不能依靠程序退出、停止发送或电机 TIMEOUT=0 保证停止。不要在其他控制程序运行时启动。

在已经验证的 can0 时序（1M/5M、仲裁采样点0.75、数据采样点0.75、dsjw2）下，Ubuntu 项目根目录执行：

```bash
# 默认只读：读取参数与当前位置，不使能
python3 -B -m real_robot.hold_test

# 机械臂有支撑，准备好硬件停止措施后，执行3秒测试
python3 -B -m real_robot.hold_test --execute --seconds 3
```

测试使用电机原始反馈坐标作为每轴目标，MIT 原生 Kp=10、Kd=0.5、速度目标和前馈力矩均为0。这是低增益、有支撑的通信测试参数，不是厂家为此负载给出的 PID，也不是 PPO 训练控制器，不能保证无支撑保持。发送频率为100Hz；不构成500Hz部署验收。

执行前预装当前位置目标，再发送一次使能；正常情况下每0.5秒显示 HOLD 和最大位置偏差。位置偏差超过0.03rad、速度超过0.15rad/s、反馈超过50ms未更新、主机循环间隔超过50ms、反馈力矩超过电机额定持续力矩或温度达到70℃时结束测试并尝试失能。这些是软件测试阈值，不修改固件超时，不提供硬件急停功能。

默认运行时间3秒，可选1～5秒。必须保留结束输出；若提示 DISABLE FAILED，需要使用硬件措施，不能认为电机已失能。

本地验证：原有17项测试与新增5项测试均通过，含MIT目标编码、末轴异常时整批拒绝、非有限目标拒绝、持续力矩阈值和反馈有效性。实机效果需用户反馈确认。
